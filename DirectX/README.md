# ZICKYY MAGNET BETA

DirectX 11 / C++で動く、磁力アクションゲームのベータ版です。
仕様書の主要な遊びを先に検証できるよう、キャラクター・箱・敵・ステージは軽量なポリゴン（直方体）で表現しています。

## 実装済み

- 三人称カメラ、中央レティクル、WASD移動、ジャンプ
- N極／S極の切り替えと、半径3mの引力・反発
- 箱の取得、設置、投射、磁力パルス
- 1階：10個の磁性箱で5個の風船を割る（5秒後に再出現）
- 2階：床・天井のN極と側面のS極を切り替えながら進む磁力通路
- 3階：極性を乱す大型コイルと、接触ダメージを持つ磁性敵
- 4階：磁性箱を足場にして高所のゴールを目指す部屋
- N極を青、S極を赤で示す段階式トゥーン描画
- HP、得点、極性、クリア状態をウィンドウ上部に表示

## 操作

| 入力 | 動作 |
| --- | --- |
| `WASD` | 移動 |
| マウス / 矢印 / `Q` `E` | カメラ操作 |
| `Space` | ジャンプ |
| `V` | N極／S極を切り替え |
| `C` | 近くの箱を持つ／置く |
| `B` | 磁力パルス／持っている箱を投げる |
| `1`～`4` | 検証する階を切り替え |
| `R` | 現在の階をリセット |
| `Tab` | マウス捕捉を解除／再開 |
| `Esc` | 終了 |

## ビルドと起動

1. Visual Studio 2022で`GM_31.sln`を開きます。
2. `Debug | x64`または`Release | x64`を選びます。
3. ソリューションをビルドして実行します。

通常起動では磁力ベータ版へ直接入ります。統合前のランナー／ワイヤー機能を回帰確認するときだけ、起動引数に`--title`を指定します。

必要環境はWindows 10/11、Visual Studio 2022、「C++によるデスクトップ開発」ワークロード、Windows SDKです。

## 自動テスト

Visual Studioのx64 Native Toolsコマンドプロンプトで実行します。

```bat
cl /nologo /EHsc /std:c++17 /W4 /WX tests\magnetLogicTests.cpp /Fe:x64\magnetLogicTests.exe /Fo:x64\magnetLogicTests.obj
x64\magnetLogicTests.exe
```

極性の反転、引力／反発方向、距離減衰、当たり判定、風船の再出現時間を検証します。

## 3プロジェクトの統合方針

- `DM31_Game`：シーン、ゲームオブジェクト、DirectX 11描画基盤
- `wire-hunter-prototype`：入力、三人称カメラ、固定更新、既存アセットとx64ビルド基盤
- `sp31-master`：段階式ライティングの考え方を磁力用トゥーンシェーダーへ適用

リポジトリ同士を履歴ごと混ぜず、保守しやすい単一の`DirectX`プロジェクトへ必要な責務だけを統合しています。

## ベータ版の制限

- モデルとステージはポリゴン中心で、完成用アニメーションや演出は未実装です。
- UIはレティクルとウィンドウタイトルによる検証表示です。
- 物理はゲーム専用のAABB判定で、汎用物理エンジンは使用していません。
- 各階はキーで切り替えて検証します。階段・ロード・セーブは完成版の対象です。

実装の中心は`magneticPrototype.cpp`、カメラは`magneticCamera.cpp`、描画は`shader/magnetToonVS.hlsl`と`shader/magnetToonPS.hlsl`です。
